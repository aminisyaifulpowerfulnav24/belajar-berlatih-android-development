# **3. Membuka Kotlin Playground**
  Pada browser web di komputer, buka [Kotlin Playground](https://developer.android.com/training/kotlinplayground?hl=id)

  Anda akan melihat halaman web yang mirip dengan gambar ini:

```kotlin
  /**
 * You can edit, run, and share this code.
 * play.kotlinlang.org
 */
fun main() {
    println("Hello, world!")
}
```
[Jalankan di Kotlin Playground](https://pl.kotl.in/FHMYOBVFe)
