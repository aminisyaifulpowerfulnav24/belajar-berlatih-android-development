# **3. Membuka Kotlin Playground**
  Pada browser web di komputer, buka [Kotlin Playground](https://developer.android.com/training/kotlinplayground?hl=id)

  Anda akan melihat halaman web yang mirip dengan gambar ini: <br />
  <img width="650" alt="Kotlin Playground" src="https://developer.android.com/static/codelabs/basic-android-kotlin-compose-first-program/img/7844a522159be53c_1440.png?hl=id" />

  Sudah ada beberapa kode default yang terisi di editor kode. Tiga baris kode berikut membentuk program sederhana: <br />

```kotlin
fun main() {
    println("Hello, world!")
}
```

  Meskipun Anda belum pernah melakukan pemrograman sebelumnya, dapatkah Anda menebak apa yang dilakukan program tersebut?
