# belajar-berlatih-android-development
Halo teman-teman, selamat datang di ruang tempat saya berlatih untuk menjadi android development😉!

saya ingin mengetahui apa saja fundamental dasar android development dari nol hingga mahir untuk menjadi pengembang aplikasi navigasi GPS gratis dan bersumber dari open-source

## Peta Jalan Belajar Android Development
[] Dasar-dasar kotlin
[] Membuat UI dengan Jetpack Compose
[] Integrasi API & Networking (Termasuk MapLibre beserta mesin perutean dan MapLibre Navigation Core)
[] Arsitektur Model-View-ViewModel (MVVM) & Clean Architecture

## Struktur Latihan
* **01-Fundamental-Kotlin**: Latihan logika dasar dan Object-Oriented-Programming (OOP) Kotlin
* **02-Android-UI**: Project latihan membuat aplikasi peta sederhana hingga desain UI/UX untuk aplikasi navigasi GPS

## Tech Stack & Tools
**Bahasa**: Kotlin
**IDE**: Android Studio
**Arsitektur**: Model-View-ViewModel (MVVM)
**Library Utama**: Jetpack Compose, Retrofit, Gson, hingga ke MapLibre untuk pembuatan peta navigasi GPS
